# Q64

**Dark Node Game Studio** — our first game.

Q64 is a complete, premium chess game: a cinematic dark sci-fi chess experience with a real
career, cups and tournaments, and LUPUS, an AI chess companion who talks, coaches, and plays.

## Features
- Career mode — climb from a Dark Node rookie to World Champion against real chess legends
- Cups & Tournaments — win trophies through bracketed runs
- Play vs Computer, Local two-player, and LUPUS (AI companion)
- Puzzles, Learn, Game History, Profile & stats — all saved on your device
- LUPUS's real brain — in-game chat and post-game coaching
- Mobile-first, installable (PWA)

Almost everything works fully offline. Online play vs real humans, chatting with LUPUS,
and creating an account are the only parts that use a connection.

## Run locally
```bash
npm install
npm run dev   # http://localhost:3001
```

## Tech
Next.js 14 · TypeScript · Tailwind CSS · chess.js · Groq (LUPUS brain)
